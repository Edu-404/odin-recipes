# Odin Recipes

This project is part of **The Odin Project's** Foundations curriculum, where I put into practice what I learned in the *Git Basics* and *HTML Foundations* lessons.

## Description
The website consists of a main index page that links to various recipe pages. 

## Features & Skills Demonstrated
In this project, I will demonstrate the following skills:
- Setting up a Git repository and tracking changes with commits
- Structuring web pages using semantic HTML elements
- Creating internal links between multiple pages (`<a>` tags)
- Organizing content with ordered and unordered lists (`<ol>`, `<ul>`, `<li>`)
- Adding and configuring images (`<img>`)

> **Note:** This project focuses exclusively on HTML structure and semantic markup. No CSS was used for styling at this stage, but styles will be added in a future update!
